# Netflix Data Analysis Project

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.

The main objective of this project is to analyze Netflix content distribution, identify popular genres, understand country-wise production, study content growth trends, and extract meaningful insights using Python data analysis techniques.

---

## Dataset

Dataset Used:

**Netflix Titles Dataset**

The dataset contains information about:

- Movies and TV Shows
- Directors
- Cast
- Countries
- Release Year
- Ratings
- Duration
- Genres
- Description

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Handling Missing Values
4. Data Preprocessing
5. Exploratory Data Analysis (EDA)
6. Data Visualization
7. Insights Generation

---

## Key Analysis Performed

### 1. Movies vs TV Shows Analysis

Compared the distribution of Movies and TV Shows available on Netflix.

### 2. Country-wise Analysis

Identified the top countries producing Netflix content.

### 3. Release Year Trend Analysis

Analyzed Netflix content growth over different years.

### 4. Rating Analysis

Studied the distribution of Netflix content ratings.

### 5. Genre Analysis

Identified the most popular genres available on Netflix.
